# 정처기 학습노트

정보처리산업기사 **핵심 요약 001~200**을 외우는 학습 사이트 (Next.js, Vercel 배포용).

## 학습 흐름

한 화면에 한 가지 일만 하도록 3단계로 나눴습니다.

| 단계 | 화면 | 하는 일 |
| --- | --- | --- |
| 1 | 홈 | 3과목 카드(진행률) + 항목 검색 |
| 2 | 과목 | 32개 ‘이야기 묶음’ — 묶음 이야기 읽고, 번호 칩으로 바로 이동 |
| 3 | 학습 | 묶음 안 항목을 플래시카드 · 빈칸채우기 · 객관식으로. 암기 훅·연결 항목은 카드 안에 |

학습 화면의 ‘👍 알아요 / 🔁 다시 볼게요’는 진행률에 반영되고, 라이트너 간격 반복 기록(`map`)도 함께 남깁니다.
학습 기록은 누를 때마다 웹(Supabase `edu_progress` 테이블, 행 `me`)에 자동 저장되고, 브라우저 `localStorage`(`edu-info-progress-v1`)에도 사본을 둡니다. 혼자 쓰는 사이트라 로그인은 없고, 기기 간에는 더 최근 기록이 이깁니다.

## 실기 요약 테스트 (별도)

홈 맨 아래 **📝 실기 요약 테스트**(`#/exam`)는 200문항과 별개인 단답형 테스트입니다. `notes/` 요약노트 (1) 운영체제 · (2) 네트워크 · (3) 개발환경·테스트·SQL로 만든 문제가 `lib/exam.ts`에 있습니다.

- 범위(전체·편별·틀린 문제만), 문제 수, 순서 섞기를 고르고 답을 입력하면 바로 채점합니다 (대소문자·띄어쓰기·기호 무시, `a`에 인정 답안 여러 개).
- 표기만 달라 오답 처리된 답은 ‘맞게 썼어요’로 정답 처리할 수 있습니다.
- 기록(틀린 문제, 범위별 마지막 점수)은 기존 진행률과 섞이지 않게 이 브라우저의 `localStorage`(`edu-info-exam-v1`)에만 둡니다.

## 개발

```bash
npm install
npm run dev          # http://localhost:3000
npm run typecheck
npm run check:data   # 200개 항목·묶음·연결 고리 + 실기 테스트 문제 무결성 검사
npm run build
```

## 콘텐츠 수정

- `lib/items1.ts` (001~132), `lib/items2.ts` (133~200): 항목 데이터
  - `p` 본문의 `[[키워드]]` = 교재 밑줄 → 빈칸 퀴즈 정답
  - `m` 암기 훅, `r` 같이 외울 항목 번호, `c` 묶음 id, `ex` 예제
- `lib/clusters.ts`: 묶음 이름과 묶음 전체를 잇는 이야기(story)

## 배포 (Vercel)

저장소를 Vercel에 Import하면 Next.js로 자동 인식됩니다. 별도 환경 변수는 필요 없습니다(다른 Supabase를 쓰려면 `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_KEY`).
