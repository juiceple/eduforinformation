# 정처산기 연관 암기

정보처리산업기사 **핵심 요약 001~200**을 서로 연결해서 외우는 학습 사이트 (Next.js, Vercel 배포용).

## 학습 설계

| 단계 | 메뉴 | 하는 일 |
| --- | --- | --- |
| 1. 묶음으로 이해 | 📚 묶음 학습 | 200개를 32개 ‘이야기 묶음’으로 읽기. 교재 밑줄 핵심어는 분홍색 강조, ‘키워드 가리기’로 바로 셀프 테스트 |
| 2. 암기 훅 | 🔑 암기 코드 | 항목마다 두문자(상·점·비·환 등)·비유 훅. 한 장 요약 + 검색 |
| 3. 연결 고리 | 🕸️ 연관 맵 | 묶음 간·과목 간 연결(예: CPU 스케줄링 ↔ 디스크 스케줄링, 트리 운행 ↔ 수식 표기법) |
| 4. 인출 + 간격 반복 | ✍️ 빈칸 · 🃏 카드 · 🎯 객관식 | 초성 힌트 빈칸, 라이트너 상자(1·2·4·7·15일) 플래시카드, 같은 묶음에서 오답을 고르는 객관식 |

학습 기록은 브라우저 `localStorage`에만 저장됩니다(서버·로그인 없음).

## 개발

```bash
npm install
npm run dev          # http://localhost:3000
npm run typecheck
npm run check:data   # 200개 항목·묶음·연결 고리 무결성 검사
npm run build
```

## 콘텐츠 수정

- `lib/items1.ts` (001~132), `lib/items2.ts` (133~200): 항목 데이터
  - `p` 본문의 `[[키워드]]` = 교재 밑줄 → 빈칸 퀴즈 정답
  - `m` 암기 훅, `r` 같이 외울 항목 번호, `c` 묶음 id, `ex` 예제
- `lib/clusters.ts`: 묶음 이름과 묶음 전체를 잇는 이야기(story)

## 배포 (Vercel)

저장소를 Vercel에 Import하면 Next.js로 자동 인식됩니다. 별도 환경 변수는 필요 없습니다.
